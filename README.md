# superstore-sales-profit-analysis
Retail sales and profit analysis using SQL (SQLite), Python, and Power BI to derive actionable business insights.

This project analyzes a retail superstore dataset using SQL (SQLite) and Python.

Key tasks performed:
- Sales and profit analysis by category and region
- Impact of discounts on profitability
- Data cleaning and exploratory data analysis
- Power BI dashboard for business insights

Tools Used: Python, Pandas, SQL (SQLite), Power BI
